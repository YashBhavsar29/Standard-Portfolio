Overview

This is a 2D chess game I wrote in Python with the Pygame library, taking it from the rules of the game to the interface on screen, with no game engine involved. It supports all of chess's moves and presents them on a clean, good-looking board.

What it covers

Complete move setAll of chess's moves are supported.
2D graphical interfaceA styled board and piece artwork drawn in a Pygame window.
Plain PythonA desktop game built with Python and Pygame, no engine.
Tidy project layoutCode lives in Scripts and the artwork in Assets.
02

What I Built

I built the whole project myself: the chess logic, the interface, and the game loop that ties them together.

  • Chess rules: Wrote the movement rules so that every piece type moves and captures correctly.
  • Graphical interface: Built the board and piece rendering in Pygame, with artwork kept in its own Assets folder.
  • Project structure: Kept game scripts and assets in separate folders so the code stays easy to navigate.
03

Build Notes

Tech stack: Python · Pygame · Git / GitHub

Chess is a good test of turning rules into code, because every piece has its own movement and there are many exceptions to get right. Writing it directly in Python and Pygame meant handling everything myself, from the rules to drawing the board.

The full source is on GitHub if you want to read through it.
